# PWA status

BreadTrans hiện được phát hành như một responsive web application. Khả năng cài đặt dưới dạng Progressive Web App, offline, background sync và push notification được hoãn lại, không thuộc phạm vi triển khai luận văn hiện tại.

Không có service worker, install prompt, offline exam hoặc private API cache đang được kích hoạt. Icon/logo website thông thường vẫn được giữ lại; không có nút cài đặt ứng dụng trong giao diện.

Định vị dùng cho báo cáo:

> Phiên bản hiện tại của BreadTrans tập trung vào trải nghiệm web đáp ứng (responsive web). Khả năng cài đặt dưới dạng Progressive Web App được định hướng là chức năng mở rộng trong tương lai và chưa được kích hoạt trong phạm vi triển khai hiện tại.
